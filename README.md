# Grab Rider Safety & Delivery Spatial Matching Engine

> A Decision Support System (DSS) and User Experience (UX) framework designed to eliminate motorcycle delivery hazards for oversized and bulky cargo.

---

## 📌 Project Overview
Motorcycle delivery riders on on-demand platforms often face severe safety hazards when assigned oversized, heavy, or awkwardly shaped cargo (such as multi-tier cakes or bulky boxes) without prior spatial warning. Current dispatch platforms match vehicles based primarily on parcel weight rather than volumetric dimensions. 

This project proposes a **spatial Decision Support System (DSS)** paired with **enhanced UI/UX components** that mandates volumetric dimension inputs ($L \times W \times H$), calculates volumetric size, automatically re-routes oversized items to 4-wheel vehicles, and provides upfront visual hazard badges to riders before job acceptance.
